## 1. 安全要件一覧

### SR-101: 緊急停止機能

| 項目 | 内容 |
|------|------|
| ASIL | ASIL-C |
| カテゴリ | 機能安全 |
| 説明 | 異常検知時に500ms以内にシステムを安全状態に停止させる機能。オペレータによる手動停止と自動停止の両方をサポート。 |
| 検証方法 | システムテスト |
| 検証状況 | 検証完了 |
| 関連ハザード | H-101, H-103 |
| 備考 | 全20シナリオで検証完了。応答時間は平均320ms。 |

### SR-102: フェールセーフ動作

| 項目 | 内容 |
|------|------|
| ASIL | ASIL-B |
| カテゴリ | 機能安全 |
| 説明 | 単一故障発生時にシステムが安全側に動作すること。センサー故障、通信途絶、電源異常を対象とする。 |
| 検証方法 | 統合テスト |
| 検証状況 | 検証完了 |
| 関連ハザード | H-101, H-102, H-103 |
| 備考 | フォールトインジェクションテストにより3回検証実施。 |

### SR-103: 自己診断機能

| 項目 | 内容 |
|------|------|
| ASIL | ASIL-B |
| カテゴリ | 診断 |
| 説明 | システム起動時および定期的（10分間隔）に自己診断を実行し、異常を検出した場合はオペレータに通知する。 |
| 検証方法 | 単体テスト |
| 検証状況 | 検証中 |
| 関連ハザード | H-104 |
| 備考 | 診断項目15件中12件の検証完了。残り3件は2026年2月検証予定。 |

### SR-104: 冗長化設計

| 項目 | 内容 |
|------|------|
| ASIL | ASIL-A |
| カテゴリ | アーキテクチャ |
| 説明 | 主要コンポーネント（センサー、制御ユニット、通信モジュール）を二重化し、一方の故障時も動作を継続可能とする。 |
| 検証方法 | 設計レビュー |
| 検証状況 | 検証完了 |
| 関連ハザード | H-101, H-102, H-105 |
| 備考 | 設計レビュー2回実施。指摘事項3件はすべて対応済み。 |

### SR-105: 異常検知機能

| 項目 | 内容 |
|------|------|
| ASIL | ASIL-C |
| カテゴリ | 診断 |
| 説明 | センサー値の異常（範囲外、急変、固着）を検知し、100ms以内に警告を発出する機能。 |
| 検証方法 | システムテスト |
| 検証状況 | 検証中 |
| 関連ハザード | H-101, H-104 |
| 備考 | 異常パターン8種類のうち5種類の検証完了。残り3種類は検証中。 |
