# GSN構造（Goal Structuring Notation）

**文書ID:** GSN-TEST-001  
**作成日:** 2026-01-20  
**作成者:** 安全論証チーム

## 1. GSN概要

**目的:** 安全制御システムの安全性を構造化された形式で論証する  
**準拠規格:** ISO 26262, GSN Community Standard

## 2. GSN構造図（テキスト表現）

```
G1 [Goal]
│ 「システムは安全に運用できる」
│
├─ C1 [Context]
│    「ISO 26262準拠」
│
└─ S1 [Strategy]
     「ハザード分析による安全性論証」
     │
     ├─ G1.1 [Sub-Goal]
     │    「すべてのハザードが識別されている」
     │    └─ Sn1 [Solution/Evidence]
     │         「ハザード分析レポート」
     │         参照: TEST_Hazard_Analysis.txt
     │
     ├─ G1.2 [Sub-Goal]
     │    「識別されたハザードに対策が実施されている」
     │    └─ Sn2 [Solution/Evidence]
     │         「リスク対策実施記録」
     │         参照: TEST_Risk_Summary.txt
     │
     └─ G1.3 [Sub-Goal]
          「安全要件が検証されている」
          ├─ Sn3 [Solution/Evidence]
          │    「安全要件仕様書」
          │    参照: TEST_Safety_Requirements.txt
          └─ Sn4 [Solution/Evidence]
               「検証結果サマリー」
               参照: TEST_Verification_Results.txt
```
